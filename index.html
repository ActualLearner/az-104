📓 Active Error Journal: 71 Key Azure Mechanics Mastered

Forensic error logs from practice exams & diagnostic drills (see SOP Protocol & Full Markdown Journal):

📄 Open Full Markdown Journal (71 Entries)

🔐 Domain 1: Identity & Governance

  • Deployments vs Properties Blade (TD Sampler Q6): Properties shows static metadata only. Exact ARM deployment timestamps, inputs/outputs, and history live in the Deployments blade.
  • Entra ID Custom Domain Verification (TD Timed Q5): Verification supports exactly two record types: TXT (Primary) or MX (Fallback). Never A, CNAME, or SOA.
  • Control Plane vs Data Plane RBAC: Subscription Owner/Contributor grants control plane only. Reading/writing blob data requires Storage Blob Data Owner / Contributor / Reader.
  • Azure Policy Enforcement (sys.regionrestriction): Deny policies block non-compliant resources during pre-flight ARM evaluation before provisioning begins.

📦 Domain 2: Storage

  • Secondary Region Read Access (Q12): Standard GRS secondary is completely unreachable without initiating customer failover. Secondary read access requires RA-GRS or RA-GZRS.
  • AzCopy Syntax & Subfolders (TD Sampler Q7): Uploading folders recursively requires --recursive. Syntax: azcopy copy <LocalPath> <BlobURL> --recursive.
  • On-Prem VHD Upload (Q22): VM disks must be uploaded as Page Blobs (512-byte aligned) using Add-AzVhd, never Block Blobs.
  • Blob Container Leases (HTTP 412): An active lease locks blob metadata/policies. Modifying leased blobs throws 412 until you Break Lease.
  • Storage Firewalls & Dynamic Client IPs: Restricting to client IP breaks when home ISP rotates dynamic IPs. Use Entra ID auth or update firewall IP rule.

⚡ Domain 3: Compute

  • The Stopped VM Quota Trap (TD Timed Q3): Stopped (Deallocated) VMs stop billing, but STILL CONSUME vCPU quota. Only deleting VMs frees quota.
  • App Service OS Isolation (TD Timed Q2): App Service Plans support only ONE OS. Classic ASP.NET needs Windows; Python/PHP needs Linux → Minimum 2 Plans.
  • App Service Deployment Slots (TD Sampler Q3): Staging slots require Standard (S1) tier or higher. Moving tiers = Scale Up (not Scale Out).
  • Availability Set Resizing (Q16): If target VM size is not on the same cluster, resizing throws AllocationFailed until ALL VMs in the set are deallocated.
  • VM Licensing & Hybrid Benefit (AHB): Eliminates Windows Server OS fees (bills at base Linux rate). Minimum 16 cores. Toggled live via licenseType with zero downtime.

🌐 Domains 4 & 5: Networking & Monitoring

  • Load Balancer Sticky Sessions (TD Timed Q4): Route requests consistently to the same VM by setting Session persistence: Client IP (2-tuple / 3-tuple). Default 5-tuple hash does not persist.
  • P2S VPN Route Propagation (Q24/25): P2S clients do not learn new peered routes automatically. The VPN client package must be re-downloaded & re-installed.
  • Azure Advisor vs Azure Monitor (TD Sampler Q5): Azure Monitor collects raw metrics/logs; Azure Advisor provides proactive recommendations to identify idle/underutilized VMs to cut costs.
