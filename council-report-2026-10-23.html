📓 Active Error Journal & Key Azure Mechanics Mastered

Lessons extracted from your hands-on labs and diagnostic questions:

  • Storage Redundancy Reads (Q12): Standard GRS does NOT allow secondary reads without failover; RA-GRS is mandatory for secondary read access.
  • Availability Set Resizing (Q16): If resizing a VM in an Availability Set fails due to allocation cluster limits, ALL VMs in the set must be deallocated/stopped before resizing.
  • On-Prem VM Disk Upload (Q22): Uploading an on-prem `.vhd` to Azure Storage uses Add-AzVhd (Page Blob), not `Add-AzImage`.
  • P2S VPN Peering Routes (Q24/25): Point-to-Site VPN clients do NOT auto-learn routes across VNet peering; the VPN client package must be re-downloaded & re-installed.
  • Azure Policy Enforcement (`sys.regionrestriction`): Deny policies block resources during pre-flight validation. Your allowed regions are: Spain Central, UAE North, Central India.
  • Storage Account Firewalls: Restricting to client IP breaks if your home ISP rotates dynamic IPs overnight—check the "Add client IP" box or use Entra ID.
  • Blob Container Leases: An active lease locks the container; modifying policies returns 412 until you click "Break lease".
  • Control Plane vs Data Plane RBAC: Subscription Owner gives control-plane rights only. To create blob containers and access policies, you need Storage Blob Data Owner / Contributor.
